# Ginrose name and logo

Ginrose's code is free software under the GNU GPL (see [COPYRIGHT](COPYRIGHT)
and [LICENSE](LICENSE)). Its name and logo are not. This page says what you can
do with them.

They cover the name "Ginrose", the logo and wordmarks in `assets/`, and the
application ID `me.daeese.apps.ginrose` (and `me.daeese.apps.ginrose.player`).
They cover Ginrose Studio the same way: the name "Ginrose Studio", its logo,
icons and wordmark in `assets/` (`ginrose-studio*.png`, `studio-icons/`), and
the application ID `me.daeese.apps.ginrose.studio` (and
`me.daeese.apps.ginrose.studio.editor`). Below, "Ginrose" means either.

## Fine without asking

- Sharing the official builds unmodified, from
  [ginrose-flatpak](https://github.com/nunreasonable/ginrose-flatpak),
  [ginrose-studio](https://github.com/nunreasonable/ginrose-studio) or
  Flathub, including in software stores and distribution repositories.
- Building Ginrose from unmodified source, for yourself or for a distribution
  package, and calling it Ginrose.
- Saying a project works with, was based on, or was forked from Ginrose, in
  plain text, as long as it is clear it is not Ginrose.
- Using the name and logo to write about Ginrose, review it or teach it.

## Needs a new name

Anything modified beyond what a distribution needs to package it (paths, build
flags, patches that do not change what Ginrose does) is a fork, and a fork has
to use its own name, logo and application ID. That keeps people from mistaking
it for Ginrose and blaming one for the other.

In particular, nothing may be called Ginrose, use its logo or reuse its
application ID if it:

- turns off or works around the check that Roblox runs exactly as Roblox
  signed it (Ginrose Studio has no such check; that is how it is made, and
  does not make a changed Ginrose acceptable);
- loads code into Roblox, or is made or advertised for cheating or exploiting;
- passes itself off as an official build.

Ginrose Studio lets its user load what they like into Roblox Studio on their
own machine. A build or fork made or advertised to do that for cheating or
exploiting is still covered by the second point.

## Asking

For anything not covered here, open an issue at
[ginrose-flatpak](https://github.com/nunreasonable/ginrose-flatpak/issues).
